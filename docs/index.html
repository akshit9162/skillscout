A week in five commands

New skills appear daily and installed ones change upstream. Read only what moved.

CommandWhat happens
discoverSearches GitHub, clones skill folders only, scans and scores each skill.
show <id>Every flag with file and line, the full SKILL.md, overlaps.
approve <id>Copies that one skill, drops symlinks, pins the commit and a content hash.
updatesDiffs each pinned skill against upstream. Nothing is applied.
scheduleSets up a weekly job; you turn it on.

Updates arrive as a diff

When a pinned skill changes upstream, you read the diff first. Taking it re-runs the scan.

Refused

Your copy stays as it was. Only a person can pass --accept-risk; the bundled skill forbids the agent.

What it never does

  • Install on its own

    Discovery only writes a report.

  • Overwrite your skills

    It refuses folders it did not install.

  • Follow symlinks

    A link could point at ~/.ssh, so links are dropped.

  • Apply updates silently

    You read the diff first.

Your first run

With the plugin, ask your agent what’s new; it asks before each install. Set keywords first.
