Keep your agent’s skills current.

For every kind of work you do. Checked weekly, scanned first.

claude plugin marketplace add akshit9162/skillscout claude plugin install skillscout@skillscout

MIT licence. Python 3.11+, no dependencies. macOS, Linux and Windows.

REC: worth installing. High: a line to read first, like sudo in an install guide.

One agent per kind of work

Your split, in your words. Each gets an agent kept current.

Yours

Only the skill list changes. History stays on your machine.

Switch, and the rest stays out

Every installed skill loads into every session. Switch persona, and only that work’s skills and plugins do.

Undoable

Nothing moves on disk. --clear puts your settings back exactly, and an override you set yourself is never touched.

A week in seven commands

Read only what moved.

CommandWhat happens
discoverScores this week’s index of every public skill against your work, one section per persona.
show <id>Every flag with file and line, the full SKILL.md, overlaps.
approve <id>Installs that one skill, pinned to its commit. Never overwrites yours.
updatesDiffs each pinned skill against upstream. Nothing is applied.
persona buildSwaps a better installed skill into that persona’s agent.
persona useLists only that work’s skills and plugins in Claude Code. --clear undoes it.
scheduleSets up a weekly job; you turn it on.

Updates arrive as a diff

Read the diff first. Taking it re-runs the scan.

Refused
